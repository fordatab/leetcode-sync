# Add Two Integers

**Difficulty:** Easy
**Tags:** math, basic-arithmetic

## Problem

Given two integers within the range -100 to 100, compute and return their arithmetic sum. The problem requires handling both positive and negative integers correctly.

## Approach

The solution implements a direct arithmetic addition using the built-in `+` operator. The function receives two integer parameters and immediately returns their sum without any intermediate variables or additional logic. This straightforward approach leverages the language's native integer arithmetic to handle both positive and negative numbers, including overflow cases (though within the given constraints, overflow is not possible).

- **Time:** O(1)
- **Space:** O(1)
